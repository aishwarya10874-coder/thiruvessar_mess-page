# 🍛 Thiruveesar Mess 

A modern, responsive restaurant website for **Thiruveesar Mess**, an authentic South Indian non-veg restaurant located in Pallikaranai, Chennai.


## 📸 Preview

| Section | Description |
|---|---|
| Hero | Two-column layout with food image grid and floating badge |
| About | Story section with stats (years, dishes, reviews, rating) |
| Specials | Menu cards for Biryani, Prawn Thokku, Egg Kheema |
| Reviews | Google review cards from real customers |
| Visit | Address, phone, hours, and Google Maps link |

---

---

## ✨ Features

- ✅ Fully responsive single-page design
- ✅ Smooth scroll navigation with fixed navbar
- ✅ Fade-up animations using Intersection Observer
- ✅ Marquee banner with rolling text
- ✅ Menu specials cards with pricing
- ✅ Real Google Reviews section
- ✅ Google Maps integration
- ✅ Swiggy delivery link
- ✅ Click-to-call phone number

---

## 🛠️ Built With

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — Scroll effects, fade-in observer
- **Google Fonts** — Playfair Display, Inter, Noto Serif Tamil

---

## 🚀 Deployment

This site is deployed via **Netlify** connected to this GitHub repository.

Every push to the `main` branch automatically triggers a new deployment.

### To run locally:
Just open `index.html` in your browser — no build tools needed!
